# Student Grade Manager

## Project Description

Student Grade Manager is a Python application that accepts student marks and calculates the total marks, average marks, and grade.

## Features

- Enter student name
- Enter Maths mark
- Enter Science mark
- Enter English mark
- Calculate total marks
- Calculate average marks
- Calculate student grade
- Display student details

## Grade System

| Average | Grade |
|---|---|
| 90 - 100 | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | F |
